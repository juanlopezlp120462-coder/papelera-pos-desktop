- Base de datos preparada para funcionar al lado del ejecutable en Windows.

EJECUTABLE WINDOWS:
Este paquete incluye CREAR_EXE.bat y PAPELERA_POS.spec. Desde una PC Windows con Python 3.11+ conectado a Internet, ejecuta CREAR_EXE.bat. El resultado sera:
 dist\PAPELERA_POS\PAPELERA_POS.exe

IMPORTANTE:
En este entorno Linux no es posible compilar un .exe Windows real porque no hay un toolchain Windows ni PySide6 disponible. No se incluye un EXE falso; se incluye el generador real para Windows.
